# 정처기 실기 코스 백로그

시험: 2026년 3회 실기 (10월 24일~). 우선순위가 높은 것부터.

## 1. 문제 보강

### C 언어 (지금 10문제 → 목표 30문제)
실기에서 매 회차 여러 문제가 나오는데 유형이 부족하다. 정답은 반드시 `cc`로 컴파일해 실행한 결과로 넣는다.
- [ ] 함수 호출: 값 전달 vs 주소 전달(swap), 재귀(팩토리얼, 피보나치, 합)
- [ ] 포인터 심화: `*p++` vs `(*p)++`, 포인터 배열 vs 배열 포인터, 배열 뒤집기
- [ ] 문자열: `strcpy`, `strcat`, `strcmp`, 문자열 뒤집기, 대소문자 변환, 문자 세기
- [ ] 반복문: 이중 `for`, `while` vs `do-while`, `break` / `continue`
- [ ] 알고리즘 추적: 버블·선택 정렬 한 단계, 소수 판별, 약수 합, 10진수 → 2진수
- [ ] 그 밖에: 전역 vs 지역 변수 가리기, 삼항 연산자, `#define` 매크로 괄호 함정, 구조체 배열, 연결 리스트 노드 따라가기

### Java (11문제 → 20문제)
- [ ] 추상 클래스와 인터페이스, 다형성 배열(`Animal[]`) 순회 출력
- [ ] `this` / `super` 생성자 체이닝, 초기화 블록과 생성자 순서
- [ ] 예외: `try-catch-finally` 안의 `return`, 사용자 정의 예외
- [ ] 컬렉션: `ArrayList`, `HashMap` 순회 출력, `String` 메서드(`substring`, `charAt`, `split`)
- [ ] 재귀, 2차원 배열 출력

### Python (10문제 → 15문제)
- [ ] 딕셔너리·리스트 컴프리헨션 심화, `lambda` + `map` / `filter`
- [ ] 클래스와 `self`, 문자열 포매팅, `split` / `join`

### SQL (16문제 → 20문제)
- [ ] `JOIN` 결과 행 수 세기(INNER / LEFT), 서브쿼리 `IN` / `EXISTS`
- [ ] `UNION` / `UNION ALL`, `DISTINCT` + `COUNT`

## 2. 문제 품질 (2026-09-24 점검 뒤 남은 것)
- [ ] 오답을 같은 표에서 자동으로 고르다 보니 가끔 주제가 먼 보기가 섞인다 (예: 접근통제 문제에 인증 설명). 표를 더 잘게 나누거나 카드마다 오답 후보를 직접 지정할 수 있게 한다.
- [ ] Java 업캐스팅(j1)은 답을 흘리지 않는 힌트가 없어 힌트를 뺐다. 새 힌트를 직접 쓴다.
- [ ] 보안 웹 공격 표(SQL Injection·XSS·CSRF)가 3개뿐이다. 웹 공격 카드를 더 넣는다 (예: 디렉터리 탐색, 파일 업로드 공격, 클릭재킹).
- [ ] 소프트웨어 공학 유닛이 5문제(레슨 1개)다. 디자인 패턴(GoF 생성·구조·행위), 테스트 기법(동등 분할, 경계값 분석, 커버리지), 애자일·XP를 넣는다.
- [ ] 운영체제(페이지 교체 FIFO·LRU·LFU 부재 횟수, 스케줄링 SJF·HRN·RR)가 아예 없다. 유닛을 새로 만든다.
