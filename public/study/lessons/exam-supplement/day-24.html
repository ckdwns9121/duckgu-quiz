MFA Delete와 보존 잠금

MFA Delete는 S3 객체 버전의 영구 삭제나 버전 관리 상태 변경에 추가 인증을 요구한다. 유효한 MFA를 가진 버킷 소유자의 삭제를 정해진 기간 동안 금지하는 보존 정책은 아니다. Object Lock Compliance는 보호된 버전의 보존 기간 동안 루트 사용자도 그 버전을 삭제하거나 기간을 줄이지 못하게 한다. 따라서 “삭제 전에 추가 인증”과 “인증했더라도 7년간 삭제 불가”는 다른 요구다.

출처: MFA Delete, Object Lock.

외부 계정의 사본과 접근 회수

교차 계정 역할은 소유 계정에서 신규 역할 전환과 리소스 권한을 통제할 수 있게 한다. 외부 계정에 객체 사본을 전달한 뒤에는 원본의 역할 신뢰나 버킷 정책을 회수하더라도 이미 전달한 사본이 자동 삭제되지 않는다. “소유 계정이 신규 접근을 중앙 회수한다”는 요구에서는 사본 제공과 원본의 제한된 역할 접근을 구분한다. 역할로 이미 읽어 간 데이터까지 회수할 수 있다는 뜻은 아니다.

출처: 교차 계정 역할.

결과 집계와 원천 통제

Security Hub CSPM은 여러 서비스의 보안 결과와 제어 상태를 모아 확인하는 데 사용한다. 조직의 WAF 기준을 새 계정과 리소스에 적용하는 Firewall Manager, 패키지 취약점을 평가하는 Inspector를 결과 집계만으로 대체하지 않는다. 모아 보는 기능과 실제로 정책을 배포하거나 검사하는 기능을 각각 선택해야 한다.

출처: Firewall Manager, Inspector.
