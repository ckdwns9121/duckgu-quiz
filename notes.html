C 언어 함정

코드는 외우는 게 아니라 따라가는 겁니다. 변수 값을 종이에 표로 적으면서 한 줄씩 보세요.

C

a++ 와 ++a

int a = 5, b, c;
b = a++;
c = ++a;
printf("%d %d %d", a, b, c);

출력은?

7 5 7

a++는 먼저 쓰고 나중에 더함 (b=5, a=6). ++a는 먼저 더하고 씀 (a=7, c=7).

C

*(p+2) 와 *p+2

int arr[] = {10, 20, 30, 40};
int *p = arr;
printf("%d ", *(p+2));
printf("%d", *p+2);

출력은?

30 12

*(p+2) = 2칸 옮긴 곳의 값 → arr[2] = 30. *p+2 = 값을 먼저 꺼내고 +2 → 10+2 = 12. 괄호가 있으면 이동, 없으면 덧셈.

C

이중 포인터

int a = 10;
int *p = &a;
int **pp = &p;
**pp = 20;
printf("%d", a);

출력은?

20

& = 주소 가져오기, * = 주소 따라가기. **pp는 pp → p → a로 두 번 따라감. 결국 a를 바꾼 것.

C

2차원 배열 포인터

int a[2][3] = {{1,2,3},{4,5,6}};
printf("%d", *(*(a+1)+2));

출력은?

6

*(*(a+i)+j) = a[i][j]. 바깥 +1은 행, 안쪽 +2는 열 → a[1][2] = 6.

C

sizeof 와 strlen

char s[] = "hello";
printf("%d %d", sizeof(s), strlen(s));

출력은?

6 5

문자열 끝에는 보이지 않는 '\0'이 붙음. sizeof는 그것까지 세고(6), strlen은 빼고 셈(5).

C

static 지역변수

int f() {
  static int n = 0;
  n++;
  return n;
}
// main
for (int i = 0; i < 3; i++)
  printf("%d", f());

출력은?

123

static은 함수가 끝나도 값이 남음. 초기화도 처음 한 번만 됨. static이 없으면 매번 1.

C

switch 에 break 없음

int n = 2;
switch (n) {
  case 1: printf("A");
  case 2: printf("B");
  case 3: printf("C"); break;
  default: printf("D");
}

출력은?

BC

맞는 case부터 들어가서 break를 만날 때까지 아래로 계속 실행. 시험 단골 함정.

C

음수 나눗셈·나머지

printf("%d %d ", 7/2, 7%3);
printf("%d %d", -7/2, -7%3);

출력은?

3 1 -3 -1

C·Java는 정수 나눗셈에서 소수점을 그냥 버림(0 쪽으로). 나머지 부호는 앞 숫자를 따라감. Python과 다름 (아래 Python 참고).

C

비트 연산

printf("%d %d %d ", 5&3, 5|3, 5^3);
printf("%d %d", 1<<3, ~5);

출력은?

1 7 6 8 -6

5=101, 3=011. & 둘 다 1 → 001, | 하나라도 1 → 111, ^ 서로 다르면 1 → 110. 1<<3 = 1×2³. ~x = -(x+1).

C

구조체 포인터 ->

struct P { int x; int y; };
struct P s = {3, 4};
struct P *p = &s;
p->x = p->x + p->y;
printf("%d", s.x);

출력은?

7

구조체 변수는 s.x, 구조체 포인터는 p->x. p->x는 (*p).x와 같음.

PART 1 · 코드

Java 함정

핵심은 한 문장입니다. 메서드는 실제 객체(new 뒤)를 따라가고, 필드와 static은 변수 타입(앞쪽)을 따라간다.

Java

업캐스팅 + 오버라이딩

class A { void show(){ System.out.print("A"); } }
class B extends A {
  void show(){ System.out.print("B"); }
}
A obj = new B();
obj.show();

출력은?

B

타입은 A지만 실제 객체는 B. 오버라이딩된 메서드는 new 뒤의 클래스 것이 실행됨 (동적 바인딩).

Java

필드는 다형성 없음

class A { int x = 1; }
class B extends A { int x = 2; }
A o = new B();
System.out.print(o.x);

출력은?

1

변수(필드)는 오버라이딩이 안 됨. 선언한 타입 A의 x를 읽음.

Java

static 메서드

class A { static void hi(){ System.out.print("A"); } }
class B extends A {
  static void hi(){ System.out.print("B"); }
}
A o = new B();
o.hi();

출력은?

A

static 메서드는 객체가 아니라 클래스(선언 타입)에 붙음. 오버라이딩이 아니라 숨김(hiding).

Java

생성자 호출 순서

class A { A(){ System.out.print("A"); } }
class B extends A {
  B(){ System.out.print("B"); }
}
new B();

출력은?

AB

자식 생성자 첫 줄에 super()가 숨어 있음. 부모가 먼저 만들어짐.

Java

super.메서드()

class A { void f(){ System.out.print("1"); } }
class B extends A {
  void f(){ super.f(); System.out.print("2"); }
}
new B().f();

출력은?

12

super.f()는 부모 버전을 부름. 부모 것 실행 뒤 자식 나머지 실행.

Java

문자열 + 숫자

System.out.print(1 + 2 + "3" + 4 + 5);

출력은?

3345

왼쪽부터 계산. 1+2=3(숫자). 그다음 문자열을 만나면 그 뒤는 전부 이어붙이기 → "33"+4+5 = "3345".

Java

String == 와 equals

String a = "hi";
String b = "hi";
String c = new String("hi");
System.out.print((a==b) + " " + (a==c) + " " + a.equals(c));

출력은?

true false true

==는 같은 객체인지, equals는 내용이 같은지. 같은 리터럴은 한 객체를 공유, new는 새 객체.

Java

static 변수 공유

class C {
  static int cnt = 0;
  C(){ cnt++; }
}
new C(); new C(); new C();
System.out.print(C.cnt);

출력은?

3

static 변수는 모든 객체가 하나를 같이 씀. 객체마다 따로 있는 게 아님.

Java

오버로딩 vs 오버라이딩

둘의 차이는?

오버로딩: 한 클래스 안, 이름은 같고 매개변수가 다름. 반환형만 다르면 안 됨.

오버라이딩: 상속 관계, 부모 메서드를 같은 모양으로 다시 정의.

외우는 법: 로딩 = 짐(매개변수)을 다르게 싣기, 라이딩 = 부모 위에 올라타기.

Java

try-catch-finally

try {
  int x = 10 / 0;
  System.out.print("A");
} catch (ArithmeticException e) {
  System.out.print("B");
} finally {
  System.out.print("C");
}

출력은?

BC

예외가 난 줄 이후("A")는 건너뜀. finally는 예외가 나든 안 나든 무조건 실행.

Python 함정

슬라이싱은 [시작 : 끝 : 간격], 끝 번호는 포함 안 됨. 이것만 확실하면 절반은 풉니다.

Py

리스트 슬라이싱

a = [1, 2, 3, 4, 5]
print(a[1:3], a[-2:], a[::2], a[::-1])

출력은?

[2, 3] [4, 5] [1, 3, 5] [5, 4, 3, 2, 1]

번호는 0부터. [1:3] = 1번, 2번 (3번 제외). -2 = 뒤에서 두 번째. ::-1 = 거꾸로.

Py

문자열 슬라이싱

s = "Hello"
print(s[1:4], s[-1], s[:2])

출력은?

ell o He

문자열도 리스트처럼 자름. H=0, e=1, l=2, l=3, o=4.

Py

// 와 % 와 **

print(7//2, -7//2, -7%3, 2**3, 7/2)

출력은?

3 -4 2 8 3.5

Python //는 더 작은 쪽으로 내림 (-3.5 → -4). 그래서 나머지도 양수 2. C는 -3, -1. /는 항상 실수.

Py

리스트는 같이 바뀜

a = [1, 2, 3]
b = a
b.append(4)
print(a)

출력은?

[1, 2, 3, 4]

b = a는 복사가 아니라 같은 리스트에 이름을 하나 더 붙인 것. 복사하려면 a[:] 또는 a.copy().

Py

append vs extend

a = [1, 2]; b = [1, 2]
a.append([3, 4])
b.extend([3, 4])
print(a, len(a), b, len(b))

출력은?

[1, 2, [3, 4]] 3 [1, 2, 3, 4] 4

append는 통째로 한 칸에 넣음. extend는 하나씩 풀어서 넣음.

Py

range

print(list(range(5)), list(range(1, 10, 3)), list(range(5, 0, -2)))

출력은?

[0, 1, 2, 3, 4] [1, 4, 7] [5, 3, 1]

range(시작, 끝, 간격). 슬라이싱처럼 끝은 포함 안 됨.

Py

리스트 컴프리헨션

print([x*2 for x in range(5) if x % 2 == 0])

출력은?

[0, 4, 8]

뒤에서부터 읽기: 0~4 중 짝수(0, 2, 4)만 골라서 → 2배.

Py

set 연산

a = {1, 2, 3}; b = {2, 3, 4}
print(a & b, a | b, a - b)

출력은?

{2, 3} {1, 2, 3, 4} {1}

& 교집합, | 합집합, - 차집합. set은 중복이 없음.

Py

print 의 sep, end

print(1, 2, 3, sep="-", end="!")
print("A")

출력은?

1-2-3!A

sep = 값 사이, end = 끝에 붙일 것(기본은 줄바꿈). end를 바꿔서 줄이 안 바뀜.

dict 순회

ab0

SQL 함정

SQL

COUNT(*) vs COUNT(열)

점수 열이 90, NULL, 80인 3행 테이블에서 COUNT(*)와 COUNT(점수)는?

3, 2

COUNT(*)는 행 수, COUNT(열)은 NULL을 빼고 셈. SUM, AVG도 NULL 무시.

SQL

WHERE vs HAVING

둘의 차이는?

WHERE: 묶기 전 행을 거름. HAVING: GROUP BY로 묶은 후 그룹을 거름.

COUNT, AVG 같은 집계 조건은 HAVING에.

SQL

LIKE 기호

'김%', '김_', '%김%'의 뜻은?

% = 글자 0개 이상, _ = 딱 한 글자.

김으로 시작 / 김+한 글자(두 글자 이름) / 김이 어디든 들어감.

SQL

DELETE · TRUNCATE · DROP

셋의 차이는?

DELETE: 행 삭제 (DML, 조건 가능, 되돌리기 가능).

TRUNCATE: 행 전부 삭제, 구조는 남음 (DDL).

DROP: 테이블 자체를 없앰 (DDL).

SQL

DDL · DML · DCL

각각 어떤 명령어?

DDL(정의): CREATE, ALTER, DROP, TRUNCATE

DML(조작): SELECT, INSERT, UPDATE, DELETE

DCL(제어): GRANT, REVOKE, COMMIT, ROLLBACK

외우는 법: 정의 = 틀, 조작 = 데이터, 제어 = 권한.

SQL

GRANT / REVOKE 문법

GRANT SELECT ON 학생 TO 홍길동 WITH GRANT OPTION;
REVOKE SELECT ON 학생 FROM 홍길동 CASCADE;

빈칸으로 자주 나오는 단어는?

주는 건 TO, 뺏는 건 FROM.

WITH GRANT OPTION = 받은 사람도 남에게 줄 수 있음. CASCADE = 그 사람이 준 권한까지 연쇄로 회수.

SQL

BETWEEN, IN

점수 BETWEEN 80 AND 90에 80과 90이 포함되나?

둘 다 포함

80 ≤ 점수 ≤ 90. IN (1, 3)은 1 또는 3.

SQL

ORDER BY 기본값

ASC, DESC를 안 쓰면?

ASC (오름차순)

작은 것부터. 큰 것부터는 DESC.

종류규칙외우는 법

PART 4

UML, 그림으로 외우기

UML은 소프트웨어 설계도를 그리는 공통 규칙입니다. 외울 건 딱 세 덩어리: 다이어그램 종류(구조 vs 행위), 관계 6가지(선 모양), 기호 몇 개.

1단계: 다이어그램은 두 편으로 나뉜다구조(정적) = 사진. 무엇이 있는지. 행위(동적) = 동영상. 무엇이 일어나는지.문제에서 "시간", "순서", "상태 변화", "흐름"이 보이면 행위, "구성", "관계", "배치"가 보이면 구조입니다.

구조 다이어그램 (사진)

클 · 객 · 컴 · 배 · 복 · 패

클래스: 클래스와 관계. 설계도 (가장 많이 나옴)

객체: 특정 순간의 실제 객체들. 설계도로 지은 집 사진

컴포넌트: 부품(모듈) 사이 관계

배치: 서버·기기 같은 물리적 배치. 서버실 배치도

복합체 구조: 클래스 내부 구조

패키지: 묶음(폴더) 관계

"클래스 객체 컴퓨터 배치 복잡해 패스"로 외우기

행위 다이어그램 (동영상)

유 · 시 · 커 · 상 · 활 · 타 · 상호

유스케이스: 사용자(액터)가 할 수 있는 기능. 메뉴판

시퀀스: 객체끼리 시간 순서로 메시지 주고받기. 카톡 대화 순서

커뮤니케이션: 시퀀스와 같은 내용을 연결 관계 중심으로

상태: 한 객체의 상태 변화. 신호등, 주문(접수 → 배송 → 완료)

활동: 처리 흐름. 순서도(flowchart)

타이밍: 시간에 따른 상태 변화

상호작용 개요: 여러 상호작용을 묶어 큰 흐름

"유시커 상활 타상"

2단계: 관계 6가지는 선 모양으로 구분실선이면 진짜 붙어 있는 관계, 점선이면 약한 관계. 빈 삼각형은 "상속 계열", 마름모는 "전체-부분".
연관 (Association)

서로 알고 지냄. 실선. 예) 학생 — 강의

의존 (Dependency)

잠깐 빌려 씀. 점선 + 열린 화살표. 예) 메서드 매개변수로 잠깐 사용

일반화 (Generalization)

상속. 실선 + 빈 삼각형이 부모를 가리킴. 예) 강아지 → 동물 (is-a)

실체화 (Realization)

인터페이스 구현. 점선 + 빈 삼각형. Java의 implements

집합 (Aggregation)

전체-부분, 부분이 따로 살 수 있음. 빈 마름모가 전체 쪽. 예) 컴퓨터 ◇— 마우스

포함·합성 (Composition)

전체가 없어지면 부분도 같이 없어짐. 채운 마름모. 예) 집 ◆— 방

마름모 헷갈릴 때속이 꽉 찬 마름모 = 관계도 꽉 묶임(같이 죽음). 속이 빈 마름모 = 느슨함(따로 삶).
